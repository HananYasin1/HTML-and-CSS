# HTML-and-CSS

## 1. Bootstrap Cinema Project
In this project, I utilized **Bootstrap 5** to create a responsive movie showtime website. 
- **Features:** 
  - Integrated a sticky navigation bar with HTML bookmarks.
  - Utilized Bootstrap Card Decks to display movie information.
  - Implemented Info Pill Badges for movie showtimes.
  - Customized "Kong: Skull Island", "Ghost in the Shell", and "Beauty and the Beast" listings.

## 2. Interactive Personal Portfolio
A custom-built portfolio using raw **HTML and CSS** to demonstrate core design principles.
- **Technical Highlights:**
  - **Video Integration:** Autoplaying, muted, looped background video with text overlay.
  - **CSS Filters:** Applied hue and sepia filters to images.
  - **Layouts:** Created a two-column responsive layout and a fixed navigation menu.
  - **Interactivity:** Image overlay fade effects and paragraph hover states.
  - **Tables:** Custom styled data tables with cell padding and header coloring.
